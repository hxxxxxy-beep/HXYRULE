# HXYRULE Mac Helper

Local HTTP helper on `127.0.0.1:17934`.

```bash
./install.sh --extension-id YOUR_EXTENSION_ID \
  --video-dir /Volumes/External/HXYRULE \
  --player iina
```

Pairing file: `~/Library/Application Support/HXYRULE/extension-config.json`

Uninstall: `./uninstall.sh` (keeps files under the video root).
